# AIWA AIWA — landing page

Single-page site for AIWA AIWA, a performance arts studio in Gellerup, Denmark.

Static HTML with no build step. Open `index.html` in a browser to preview, or serve the folder:

```
python3 -m http.server 8000
```

Design follows `aiwa-aiwa-brand.md`: black and white foundation, one accent colour per pillar (Productions magenta, Keynotes orange, Community acid green) used sparingly, Anton for display type and Archivo for body, no gradients or shadows.

Facts (show dates, venues, ticket links, team) come from https://aiwaaiwa.dk/; the copy is rewritten in the current brand voice.

Deployed with GitHub Pages from the `main` branch.
